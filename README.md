## Q1 Ben & Jerry's Ice Cream Machine: A Geometric Distribution Experiment

### Research Question

How many attempts are required to obtain an ice cream from the
Ben & Jerry's machine at NUS UTown, and can this process be
reasonably modeled using a geometric distribution?

### Hypothesis

If each attempt is independent and has a constant probability p
of success, the number of attempts until the first successful
ice cream should follow a geometric distribution.

Since one attempt costs SGD 1 and an ice cream is worth
approximately SGD 6, p = 1/6 provides a simple initial
break-even benchmark. However, this assumption is not used as
the empirical estimate of p.

### Data Collection

For each observed participant, I recorded the number of attempts
from their first attempt until their first successful ice cream.

No personally identifiable information was collected.

### Analysis

1. Estimate p using maximum likelihood.
2. Calculate a 95% confidence interval.
3. Compare the empirical distribution with the fitted geometric model.
4. Examine whether the empirical success probability changes with
   attempt number.
